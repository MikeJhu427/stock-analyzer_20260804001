# 📈 台股量化與基本面雙軌分析平台 
**(Taiwan Stock Quant & Fundamental Analysis Platform)**

基於 Python 與 Streamlit 開發的全方位台股技術面量化與機構級基本面分析系統。本系統採用**核心邏輯抽離（Single Source of Truth）**的三層模組化架構，打破傳統單一技術指標或財報數據的盲點，結合**左側抄底**、**右側突破**、**雙指標共振**、**兩階段回測走揚年線**以及**低位長下引量縮突破**等技術面量化演算法，並導入**幾何型態測距**、**量化狀態機**與**機構級財報三表交叉診斷引擎（V5）**，支援本機互動式儀表板與雲端定時無人值守排程掃描。

---

## 🏗️ 系統架構設計

為維持全市場自動化掃描與 Web 互動介面邏輯 100% 同步，系統將所有領域計算模型統一抽離至核心庫：

```text
├── strategy_core.py       # 核心運算庫 (指標計算、選股策略、財報診斷、幾何狀態機、三級備援爬蟲、雲端上傳)
├── app.py                 # 程式B：Streamlit 互動式視覺化分析平台 (Web UI)
├── scan_task3.py          # 程式A：全市場自動化批次掃描引擎 (CLI / GitHub Actions / Cron)
├── params_config.json     # 參數設定檔 (本機自動保存自訂策略參數組)
└── requirements.txt       # 依賴套件清單 (包含 scipy 等數學運算核心)
