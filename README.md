# 📈 台股量化與基本面雙軌分析平台 
**(Taiwan Stock Quant & Fundamental Analysis Platform)**

基於 Python 與 Streamlit 開發的全方位台股分析系統。本平台打破傳統單一技術指標或財報數據的盲點，完美結合**左側抄底**、**右側突破**、**雙指標共振**等技術面量化演算法，並導入**機構級財報三表交叉診斷引擎（V5）**，為投資人提供立體、客觀的交易決策輔助。

---

## ✨ 核心特色與功能模組

### 📊 Tab 1: 單檔深度解析 (Technical Analysis)
針對單一個股進行深入的技術與籌碼結構分析：
- **三大演算法計分**：自動判定底部翻轉（左側）、VCP 收斂（右側）與雙指標共振分數。
- **主力防守線追蹤**：動態鎖定近 60 根 K 線的「最大量防守價」，跌破即示警。
- **動能與極端訊號日誌**：採用動能標準差（Momentum Force ±1.5 Std）抓取異常爆量長紅/長黑，並條列近期重要買賣訊號。
- **VWMA 籌碼加權線**：結合均量與加權均價，判定短線實質解套賣壓與支撐。

### 🚀 Tab 2: 全市場智慧掃描 (Market Scanner)
全自動掃描台股 1700+ 檔上市櫃標的，挖掘潛力股：
- **企業級高併發抓取**：內建防阻擋機制（Session & Exponential Backoff），穩定獲取全市場數據。
- **多級別背離診斷**：同步掃描 日K 與 60分K 的 KD/MACD 多級別底背離。
- **動態濾網與時光機回測**：支援扣抵判定、年線/半年線空排與斜率計算；允許設定「歷史基準日」進行策略回測。
- **無縫跨頁連動**：掃描結果可「一鍵傳送」至基本面模組進行批次財報健檢。

### 📑 Tab 3: 財報三表交叉健檢 V5 (Fundamental Audit)
超越傳統「紅燈數量＝地雷」的死板邏輯，建立財報三表動態防誤判機制：
- **合約負債 (Contract Liabilities) 防誤判引擎**：自動抓取並交叉比對營收與現金流。精準辨識「存貨增加」究竟是滯銷地雷，還是訂單滿載的「健康備貨」。
- **雙軌評分系統**：同時計算「體質護城河分數 (0-100)」與「財務地雷風險分數 (0-100)」。
- **長天期趨勢追蹤**：涵蓋最新季度、4 季短中期趨勢，以及 8 季歷史常態軌跡。
- **七大專業診斷面板**：自動生成「風險共振提示」、「正向營運資金循環」及「下一季追蹤事項」。
